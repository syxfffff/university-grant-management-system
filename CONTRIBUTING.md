# Contributing

Open an issue for a bug or feature, then submit a focused pull request with setup/verification notes. Use Python 3.12 or 3.13 and follow the README's verification steps. Include regression tests for authorization, data validation and workflow changes.

Use fictional fixtures only. Do not submit internal university systems, screenshots, documents, names, email addresses, grant records, credentials or code you do not have permission to license. Describe security issues privately according to SECURITY.md.

Contributions are provided under the MIT license. Keep migrations in source control; do not commit the local SQLite database, virtual environment or collected static assets.
